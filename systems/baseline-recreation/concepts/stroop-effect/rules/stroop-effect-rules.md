# The Stroop Effect — Concept Rules

The Stroop Effect is the first Baseline Recreation Concept and establishes the initial
shared Concept precedent.

Canonical route:

    /baseline-recreation/concepts/stroop-effect

The page uses one selected principal artwork. Do not revive the abandoned plan for
40 or 64 separate Stroop posters.

The Stroop page should contain:

- a concise immediately visible descriptor;
- the selected principal artwork at substantial viewing size;
- an observation prompt tied to the artwork;
- an expandable comprehensive explanation;
- why the effect matters;
- historical/research context;
- references appropriate to the claims made.

The Concept is not a game. Any future Stroop demonstration should remain an optional
Concept experience module and should not impose scoring, progression or game mechanics
unless a separate design decision explicitly changes that.

Shared layout/routing changes belong in concepts/shared/. Stroop-specific visual or
behavioural changes belong in concepts/stroop-effect/.
