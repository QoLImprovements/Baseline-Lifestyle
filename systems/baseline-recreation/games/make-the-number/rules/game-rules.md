# Game Rules

Target-number puzzle using all shown numbers once with operators, brackets, tiers, hints, rerolls, and keypad input.

## Rules

1. Make The Number is a numeric reasoning game, not a generic calculator.
2. The player must use all shown numbers exactly once to reach the current target number.
3. Number/operator keypad controls must remain usable without requiring fullscreen dependence.
4. Round status, target, mistakes, round bank, clean streak, and clean bonus must remain visible and not be blocked by popups.
5. Tier rules should affect puzzle difficulty and target bands only inside this game.
6. Do not let Make The Number changes alter Detect The Word, Pairs, Track the Coin, Rule Shift, or Baseline Realm.
