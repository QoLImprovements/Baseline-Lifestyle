# Diet Log Entry Structure

Diet Log entries belong in this folder as individual files.

Each entry should be a separate record, for example:

```text
systems/baseline-food-approach/Diet Log/2026-06-16-entry-1.html
```

The Food Approach page should act as the index/control surface. It should not become the storage container for every Diet Log entry.

No static Diet Log entry bodies were found in the repository during this pass, so no individual Diet Log entry files were extracted yet.
