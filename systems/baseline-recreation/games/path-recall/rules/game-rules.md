# Path Recall rules

- Canonical route: `/baseline-recreation/games/path-recall`; account app: `pathrecall`.
- Display a contiguous, orthogonally adjacent, non-repeating route with one illuminated tile at a time.
- Once the route is hidden, the player reproduces the exact tile order by tapping/clicking. A wrong tile ends the round; no penalty for time taken.
- Starter / Field / Forge / Citadel tiers unlock by game Rank; rounds increase from 3 to 9 steps.
- Bank, XP, streaks and skills belong only to this game. Complete rounds award once. Replay unlock is limited to once per round and reduces its reward.
- Use the shared Baseline Recreation shell, account profile storage, Games/Round/Skills/Tiers/Progress tabs, toolbar and music preferences. Keep UI and CSS scoped to Path Recall/sequence games.
