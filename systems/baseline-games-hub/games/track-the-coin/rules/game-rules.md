# Game Rules

Visual tracking game where the coin is shown, hidden, shuffled under cups, then chosen with status-panel feedback.

## Rules

1. Track the Coin is a visual tracking and working-memory game, not a generic animation demo.
2. The coin should be shown first, covered, shuffled, then resolved clearly after the player chooses a cup.
3. Result feedback belongs in the game status panel and cup reveal state, not in nuisance popups.
4. The selected cup, correct cup, and final result must remain visible long enough for the player to read the outcome.
5. The colour scheme and game-window contract should remain coherent with Pairs unless a separate visual change is requested.
6. Tier, unlocked tier, coin count, streak, speed, clean streak, and clean bonus should remain readable.
7. Do not let Track the Coin changes alter Pairs, Detect The Word, Make The Number, Rule Shift, or Baseline Realm.
