# Combat Sequence rules

- Canonical route: `/baseline-recreation/games/combat-sequence`; account app: `combatsequence`.
- Display a sequence of MMA movement **cues** one at a time. After the demonstration, the player taps the corresponding movements in the demonstrated order.
- This is a memory game, not a fighting simulator: no physical strikes or kicks are needed. Avoid timed pressure by default.
- Starter / Field / Forge / Citadel tiers unlock by Rank; sequence lengths and available movement vocabulary increase with difficulty.
- Bank, XP, streaks and skills belong only to this game. Complete rounds award once. Replay unlock is limited to once per round and reduces its reward.
- Use the shared Baseline Recreation shell, account profile storage, Games/Round/Skills/Tiers/Progress tabs, toolbar and music preferences. Keep UI and CSS scoped to Combat Sequence/sequence games.
