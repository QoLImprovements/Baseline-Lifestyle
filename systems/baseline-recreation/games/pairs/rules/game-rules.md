# Game Rules

Memory matching with tiered boards, clean status feedback, skill progression, and account-bound Bank rewards.

## Rules

1. Pairs is a visual memory and matching game, not a generic card component.
2. The player should select a board tier, start a board, reveal cards, and resolve matches through the visible board/status area.
3. Round status belongs inside the game window. Do not use nuisance popups for normal result feedback.
4. Tier, moves, matched count, round bank, streak, clean streak, and clean bonus should remain readable.
5. Each physical card gets one first selection without breaking clean status. A mismatch breaks clean status only when at least one selected card has been selected before. Bank loss for a repeated miss applies only when both mismatched cards have been selected before. Hints do not count as a card selection.
6. Hints, repeat-miss deductions, and reward rules must stay scoped to Pairs only.
7. Do not let Pairs changes alter Track the Coin, Detect The Word, Make The Number, Rule Shift, or Baseline Realm.
