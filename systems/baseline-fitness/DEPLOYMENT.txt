Baseline Fitness deployment files

Upload the entire systems/baseline-fitness folder so the HTML, CSS and JavaScript voice runtime stay together on localhost and the public website.

Required public paths:
- /systems/baseline-fitness/baseline-fitness.html
- /systems/baseline-fitness/css/baseline-voice.css
- /systems/baseline-fitness/js/baseline-voice.js
- /systems/baseline-fitness/js/baseline-voice-access.js

The page uses root-relative URLs, so the same files work on localhost and on the production domain. No Apache-only fallback is used for these assets.
