# Game Rules

Rule-switching challenge for flexible attention, impulse control, deliberate selection, and adapting when instructions change.

## Rules

1. Rule Shift is a rule-switching and attention-control game, not a generic multiple-choice panel.
2. The current rule must remain visible and understandable before the player chooses a card.
3. Rule changes should be shown through the game board/status area rather than disruptive popups.
4. Tier, streak, best streak, bank, clean streak, and clean bonus should remain readable.
5. Timing and rule complexity must stay scoped to Rule Shift only.
6. Do not let Rule Shift changes alter Pairs, Detect The Word, Make The Number, Track the Coin, or Baseline Realm.
