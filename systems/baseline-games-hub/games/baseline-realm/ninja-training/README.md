# Ninja Training

Ninja Training uses the current original dense-forest presentation and the established Realm progression model. Alder Veil runs through Cedar-Root Passage, Lantern-Moss Run and Warden’s Deepwood against the Mossblade Pursuer, Gloam-Rope Raider and Hollow-Crown Warden.

## Sprite-sheet specification

The current presentation uses three repeatable forest layers and six original character/enemy sheets in this module. Dash Cut and throw are one-shot animations; Shuriken projectile: 840 ms.

## Performance controls

IntersectionObserver and document.visibilityState pause cosmetic work off-screen. Compositor-friendly transforms and background-position are used. Under prefers-reduced-motion, continuous parallax and looping playback stop.
