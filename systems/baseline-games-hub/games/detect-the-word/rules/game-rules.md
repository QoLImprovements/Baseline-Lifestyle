# Game Rules

Word deduction with 3–7 letter tiers, typed/in-game keypad input, limited guesses, and Wordle-style feedback.

## Rules

1. Detect The Word is a word-deduction game, not a generic text input exercise.
2. The player should use the visible word board, feedback cells, guess count, and status panel to understand the round.
3. The in-game keyboard/keypad must be usable without forcing fullscreen dependence.
4. Feedback must stay visible in the game status panel and word grid rather than being blocked by popups.
5. Letter tiers, guesses, round bank, clean streak, and clean bonus should remain readable on mobile and desktop.
6. Do not let word-game changes alter number-game, card-game, coin-tracking, rule-shift, or Baseline Realm mechanics.
